## BookForge 1.0 — Initial Windows Release
<img width="1314" height="840" alt="imagen" src="https://github.com/user-attachments/assets/ec53a2da-e180-4ef3-b313-557e6e456ea1" />

The first public release of BookForge, a Windows desktop application for batch EPUB-to-MOBI conversion and ebook library management.

### Highlights
- Batch conversion powered by Calibre.
- Library inventory and preflight reports.
- Configurable conversion concurrency.
- Error tracking and retry support.
- Job state persistence and recovery features.
- Exact duplicate detection using SHA-256.
- CSV reports for duplicate analysis.
- Saved profiles and dark/light themes.

### Requirements
- Windows 10/11
- Windows PowerShell 5.1
- Calibre installed

### Installation
Download and extract the ZIP package, then run `Abrir_BookForge.vbs` or `Abrir_BookForge.bat`.

**Recommendation:** Test with a small ebook collection before processing your full library. Back up your files first.

This is the initial release. Please report reproducible bugs and suggestions through GitHub Issues.
